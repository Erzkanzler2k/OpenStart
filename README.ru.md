![Меню OpenStart](docs/menu.png)

Один exe на Rust. Без установки, служб и прав администратора — ничего стороннего не
требуется. Программа забирает клавишу Win, читает ярлыки, которые уже есть у Windows, и
рисует меню сама.

Для тех, кому нужно меню «Пуск» такое, как он выбрал, — и без фоновой службы или драйвера
ради этого.

## Главное

- **Win открывает, Win закрывает** — как и Esc, клик мимо или запуск программы.
- **Кнопка «Пуск» на панели задач тоже работает** — клик открывает наше меню, а не системное.
- **Живёт в трее** — без кнопки на панели задач и без окна в Alt+Tab, переживает
  перезапуск `explorer`.
- **Семь стилей** — Windows 7, Modern, Windows 10, Windows 11, Windows App, Windows Pro,
  Windows 10X. Каждый нарисован с нуля.
- **Настоящие программы и иконки** — читает папки меню «Пуск», ищет на ходу.
- **Один exe** — скопируйте куда угодно и запустите; настройки лежат в профиле.

## Возможности

### Меню

- Открывается по **Win**, закрывается по **Win**, **Esc**, клику мимо или запуску
  программы.
- Сетка закреплённых, которую выбираешь ты: правый клик по программе закрепляет её,
  повторный снимает. Порядок сохраняется.
- Быстрые ссылки справа: Документы, Загрузки, Музыка, Изображения, Панель управления,
  Параметры, «Выполнить».
- Меню питания в нижней панели.
- Сочетания Win (Win+E, Win+R, Win+X, …) уходят системе.

### Поиск

- Совпадения на ходу: название с этого слова — выше, слово с этого слова — ниже, любая
  подстрока — в конце.
- **↑ / ↓** двигают выбор, **Enter** запускает.
- Всё локально: папки меню «Пуск» сканируются при старте, индекса и сети нет.

### Внешний вид

| Windows 11 | Настройки |
| --- | --- |
| ![Меню](docs/menu.png) | ![Настройки](docs/settings.png) |

- Семь нарисованных стилей, светлая и тёмная схема, регулируемая прозрачность.
- Фон — снимок рабочего стола под меню: вид акрила из статичной картинки, а не живое
  размытие.
- Окно настроек с превью стилей, переключателями и ползунком; изменения применяются сразу.

### Система

- Ни кнопки на панели задач, ни окна в Alt+Tab — только значок в области уведомлений.
- Левый клик по значку открывает меню, правый — «Открыть меню», «Настройки», «Выход».
- Один экземпляр: повторный запуск лишь открывает настройки в работающем приложении
  (`OpenStart.exe --settings`).
- Автозапуск при входе — переключателем; это единственная запись в реестр
  (`HKCU\...\Run`).
- Если нужен лог: `%APPDATA%\OpenStart\openstart.log` хранит строку старта и паники.

## Установка

1. Скачайте `OpenStart.exe` из [Releases](https://github.com/Erzkanzler2k/OpenStart/releases).
2. Запустите — значок появится в области уведомлений.
3. Нажмите **Win**.
4. Включите «Запускать при входе» в разделе **Управление**, если нужно постоянно.

Если значок скрыт, включите его: **Параметры → Персонализация → Панель задач → Другие
значки панели задач**.

## Как пользоваться

| Действие | Как |
| --- | --- |
| Открыть / закрыть меню | **Win** |
| Закрыть, ничего не запуская | **Esc**, клик мимо |
| Двигаться по результатам | **↑ / ↓** |
| Запустить выбранное | **Enter** |
| Открыть настройки | Значок в трее → «Настройки» или шестерёнка внизу меню |
| Выйти | Значок в трее → «Выход» или **Управление → Выход** |
| Сменить стиль | Раздел «Меню «Пуск»», клик по карточке |

## Настройки

Файл `%APPDATA%\OpenStart\config.json`:

```json
{
  "style": 3,
  "dark": true,
  "alpha": 242,
  "show_search": true,
  "tiles": true,
  "recent": [],
  "pinned": [],
  "start_x": 559,
  "start_y": 745
}
```

`style` — от 0 до 6: Windows 7, Modern, Windows 10, Windows 11, Windows App, Windows Pro,
Windows 10X. `start_x`/`start_y` — запомненная позиция кнопки «Пуск» на панели задач;
заполняется сама, можно удалить, чтобы кнопка выучилась заново.

## Требования

- Windows 10 или Windows 11 (x64).
- Без прав администратора, установщика и зависимостей.

## Сборка из исходников

```powershell
cargo build --release      # exe и ресурсы значка
cargo test --release       # юнит-тесты
.\target\release\openstart.exe
```

Нужен Rust 1.75+ с тулчейном MSVC. CI прогоняет тесты, релизную сборку и clippy на каждый
пуш.

## Как это устроено

- Низкоуровневый хук клавиатуры (`WH_KEYBOARD_LL`) ловит Win. Одиночный тап глушится,
  чтобы системное меню не открылось; при начале сочетания отправляется синтетическое
  нажатие Win, и система обрабатывает его как обычно.
- Меню — окно egui без рамки. Настройки — то же окно в другом режиме.
- Список программ строится обходом папок меню «Пуск» (`.lnk`), иконки берутся из оболочки
  Windows.
- Кнопка «Пуск» запоминается по пиксельной позиции и перехватывается низкоуровневым хуком
  мыши; если системное меню всё же появилось, оно сразу закрывается.
- Значок в трее — `Shell_NotifyIcon` со своим скрытым окном и меню; после перезапуска
  `explorer` добавляется заново по сообщению `TaskbarCreated`.
- Настройки лежат в `%APPDATA%\OpenStart\config.json`.

## Ограничения

- Панель задач не заменяется: перехватывается только клик по кнопке «Пуск», остальное
  остаётся системным.
- Windows 11 игнорирует пользовательские ярлыки из `WinX\Group3` — пункта в Win+X нет.
- Store-приложения (UWP) без ярлыка в меню «Пуск» в списке отсутствуют.
- Ручного закрепления плиток и перетаскивания нет.
- Замены экрана блокировки, поиска по файлам и веб-поиска нет.

## Известные конфликты

- Античиты и средства защиты, блокирующие глобальные хуки клавиатуры, могут не дать
  перехватить Win.
- Пока OpenStart запущен, Win открывает это меню, а не системное — в этом и смысл.
