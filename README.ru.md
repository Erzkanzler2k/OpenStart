![Меню OpenStart](docs/menu.png)

Один exe на Rust. Без установки, служб и записи в реестр — ничего стороннего не
требуется. Приложение перехватывает Win, читает ярлыки, которые уже есть у Windows,
и рисует меню само.

## Возможности

- **Win открывает, Win закрывает** — как и Esc, клик мимо или запуск программы.
  Без перезагрузки и без замены оболочки.
- **И кнопка «Пуск» на панели задач** — клик по ней открывает это меню, а не
  системное. Самый первый клик калибрует положение кнопки.
- **Настоящие программы** — читает папки меню «Пуск» (общую и пользовательскую),
  показывает настоящие иконки, ищет по названию на ходу.
- **Семь стилей** — Windows 7, Modern, Windows 10, Windows 11, Windows App,
  Windows Pro, Windows 10X. Каждый нарисован с нуля, а не собран из скинов.
- **Живёт в трее** — нет кнопки на панели задач и окна в Alt+Tab. Левый клик
  открывает меню, правый — «Открыть меню», «Настройки», «Выход». Значок переживает
  перезапуск `explorer`.
- **Один экземпляр** — повторный запуск просто открывает настройки в работающем
  приложении (`OpenStart.exe --settings`).
- **Настройки** — шесть разделов с превью стилей, переключателями и ползунком.
  Всё применяется сразу.
- **Автозапуск** — переключатель в «Управлении», без правки реестра.
- **Сочетания Win работают** — Win+E, Win+R, Win+X и остальные уходят системе.

## Установка

1. Скачайте `OpenStart.exe` из [Releases](https://github.com/Erzkanzler2k/OpenStart/releases).
2. Запустите. Значок появится в области уведомлений.
3. Нажмите **Win** — меню откроется.
4. Нужно постоянно? Включите «Запускать при входе» в разделе **Управление**.

Если значка не видно, включите его: **Параметры → Персонализация → Панель задач →
Другие значки панели задач**.

## Как пользоваться

| Действие | Как |
| --- | --- |
| Открыть / закрыть меню | **Win** |
| Закрыть, ничего не запуская | **Esc**, клик мимо |
| Открыть настройки | Значок в трее → «Настройки» или шестерёнка внизу меню |
| Выйти | Значок в трее → «Выход» или **Управление → Выход** |
| Сменить стиль | Раздел «Меню «Пуск»», клик по карточке |

## Требования

- Windows 10 или Windows 11 (x64).
- Без прав администратора, без установщика, без зависимостей.

## Сборка из исходников

```powershell
cargo build --release
.\target\release\openstart.exe
```

Нужен Rust 1.75+ с тулчейном MSVC.

## Как это устроено

- Низкоуровневый хук клавиатуры (`WH_KEYBOARD_LL`) ловит Win. Тап глушится, чтобы не
  открылось системное меню; когда начинается сочетание, отправляется синтетическое
  нажатие Win, и система обрабатывает его как обычно.
- Меню — окно egui без рамки внизу экрана. Настройки — то же окно в другом режиме.
- Список программ строится обходом папок меню «Пуск» (`.lnk`); иконки берутся из
  оболочки Windows.
- Фон — снимок рабочего стола под меню, уменьшенный и растянутый обратно: вид
  акрила из статичной картинки, а не живое размытие.
- Значок в трее — `Shell_NotifyIcon` со своим скрытым окном и меню; после
  перезапуска `explorer` добавляется заново по сообщению `TaskbarCreated`.
- Настройки лежат в `%APPDATA%\OpenStart\config.json`.

## Чего пока нет

- Панель задач не заменяется: перехватывается только клик по кнопке «Пуск»,
  остальное на панели остаётся системным.
- Пункта в Win+X: Windows 11 игнорирует пользовательские ярлыки из `WinX\Group3`.
- UWP-программ без ярлыка в меню «Пуск».
- Ручного закрепления плиток и перетаскивания.
- Замены экрана блокировки, поиска по файлам и веб-поиска.

## Известные конфликты

- Античиты и средства защиты, блокирующие глобальные хуки клавиатуры, могут не дать
  перехватить Win.
- Пока OpenStart запущен, Win открывает это меню, а не системное — в этом и смысл.

## Статус

Проверено на Windows 11: открытие и закрытие по Win, поиск, запуск программ, смена
стилей, сохранение настроек, Win+E, значок в трее и его меню, перезапуск `explorer`,
единственный экземпляр с `--settings`, клик по системной кнопке «Пуск». Не
проверено: другие раскладки, Windows 10, несколько мониторов, смена масштаба.
